# Who Are We, at 250

Immigration & Deportation in America, 2026. Daniel Alexander Smith and Anqi Wang, Harvard GSD, Fall 2026.

Website: https://anqiwang-dev.github.io/who-are-we-at-250/

The project website: the story, the interactive artifact, the comparison map, the graphs, and the data and methods behind them.

- `index.html` About · `team.html` Team · `map.html` Map · `graphs.html` Graphs · `data.html` Data · `methods.html` Methods
- `artifact.html`: the interactive artifact (the line, the world, the US, the cities); open a chapter with `#line`, `#world`, `#us` or `#city`

Static HTML, CSS and JavaScript; no build step. Run locally with `python3 -m http.server`.
